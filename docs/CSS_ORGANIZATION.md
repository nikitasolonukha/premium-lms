# CSS и проверка регрессий

`src/app/globals.css` импортирует Tailwind, затем области `src/styles`: tokens, base, student, admin, course, lesson, responsive-learning, editor, responsive, overrides. Это прежний порядок деклараций. Локальные responsive-правила редактора остаются в editor: перенос всех media queries в конец изменил бы каскад. Общие поздние overrides и staff-warning также сохраняют исходную позицию.

Разделение не меняет selectors, значения или порядок; [SHA256 и проверка полной реконструкции](qa/runs/2026-09-30-css-split-01/evidence/css-cascade.json) подтверждают только этот структурный факт. Визуальная корректность проверяется отдельно production E2E.

Каждый из 21 экранов имеет отдельный тест с настоящими ограничениями запросов. Для светлой темы проверяются семь размеров исходного ТЗ; для тёмной — 390×844, 1440×900 и 1920×1080. Сохраняются mobile/desktop light/dark screenshots, проверяются overflow, axe WCAG AA, touch targets и ошибки браузера. Отдельный сценарий проверяет drawer, клавиатуру, возврат фокуса и reduced motion. QA изолирует счётчики между независимыми сценариями; лимиты приложения не увеличиваются и не отключаются.

Новые результаты лежат в датированных каталогах `docs/qa/runs`; не заменяйте старые доказательства. Снимки сами по себе не подтверждают восстановление БД, доступ внешнего видеопровайдера или production infrastructure.
